# Neon Arrow — NVB interactive prototype

Vite + vanilla HTML/JS starter, previewable in Baodroid. The game generates removable arrows, supports hints, local progress and daily-mode UI. This is NOT a finished Android game and has no AdMob SDK.

To test: `npm install` and `npm run dev`. In Baodroid use **Cài thư viện**, then Web Preview or **Khởi tạo Android SDK & AVD** for a Capacitor APK with explicit consent. See the project source in VS Code.
