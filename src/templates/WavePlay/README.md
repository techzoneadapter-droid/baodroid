# WavePlay — NVB interactive prototype

Vite + native-web video element. Play user-selected local files and user-provided HTTP media URLs; import M3U lists. HLS playback depends on platform. No IPTV channels, subscriptions, or ads are bundled. This is NOT a production media player.

To test: `npm install` and `npm run dev`. In Baodroid use **Cài thư viện**, then Web Preview or **Khởi tạo Android SDK & AVD** for Capacitor APK with explicit consent.
